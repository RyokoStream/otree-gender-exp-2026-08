【実験の説明事項】
1. 個人情報の取り扱いと匿名化

お預かりした個人情報（氏名やID等）は、実験結果の適切な分析・解釈のために使用します。謝礼金の支払いが完了した段階で、データから氏名等の個人識別情報は速やかに削除（匿名化）されます。

{% formfield 'consent_1' %}
2. 収集したデータの利用方法

本実験で収集された属性情報（性別等）や意思決定データは、全体で約400名規模のデータセットの一部として統合され、統計的な学術分析のみに使用されます。個人の選択が単独で公表されることはありません。

{% formfield 'consent_2' %}
3. 謝礼金と決定プロセス

本実験では、説明を注意深く読み、内容を正しく理解した上で真剣に回答を行うことが、より多くの謝礼金を得る可能性を高めます。ただし、一部のタスクには確率（運）の要素が作用します。

{% formfield 'consent_3' %}
4. 謝礼金受け取りに必要な手続き（学生証コピーの提出）

謝礼金を受け取るためには、学生証の両面コピーを提出していただく必要があります。提出されたコピーは京都大学経済研究所の会計規程に基づき適切に保管され、7年経過後に確実に破棄されます。
